Community over Code Glasgow 2026 - Volunteer Follow-Up Tasks

Community over Code Glasgow 2026 - October 11-14, Hilton Glasgow

The event is over (October 11–14, 2026). Thank you to everyone who volunteered. The pre-event outreach calendar has been retired now that the event has wrapped. What remains is the post-event follow-up — the tasks below still need volunteer owners.

This page lists the post-event volunteer follow-up tasks for Community over Code Glasgow — speaker thank-yous, feedback, testimonials, collecting slides, and a lessons-learned writeup. Each task needs a volunteer owner.

NOTE: Speaker outreach tasks require coordination through Brian Proffitt and the track chairs. Speaker contact information is not publicly shared.

Pick a task, click “Volunteer for this task!” to email the planning team, and we’ll get you set up.
