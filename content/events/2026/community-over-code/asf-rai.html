Apache RAI Hackathon: LLMAO Quick Start

A short guide for joining the Apache Responsible AI (RAI) hackathon and contributing to LLMAO (apache/tooling-llmao).

1. Connect to llm.apache.org

  1. Go to https://llm.apache.org/fleet and log in.
  2. Create a key.
  3. Copy the key and keep it somewhere safe. You will need it in step 4.2.
  4. Connect your agents:
    1. Follow the instructions in Connecting your agent.
    2. Set the environment variables, using the key from step 3.

[!TIP]

Treat the key like a password. Don’t commit it to a repo or paste it into Slack.

2. Contribute

  1. Browse and pick up open issues: github.com/apache/tooling-llmao/issues
  2. Join the conversation on Slack in #llm-a-o.
  3. Learn more ways to get involved with Apache RAI: rai.apache.org/get-involved.html
