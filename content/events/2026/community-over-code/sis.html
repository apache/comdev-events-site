What We’re Working On

We’re focusing on:

  • Good first issues — small, well-scoped tasks suitable for new contributors
  • Documentation improvements — help us improve our getting-started guides and API docs
  • Bug fixes — a curated set of bugs that are approachable with mentoring support

Getting Started Before the Event

To make the most of hackathon time, we recommend:

  2. Browse the issue list and pick one that interests you
