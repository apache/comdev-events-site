Coordinator

  • Evan Rusackas — evan@apache.org

What We’re Working On

We’re focusing on approachable, well-scoped tasks that don’t require deep familiarity with the codebase to get started on:

  • Small bug fixes — GitHub issues labeled “good first issue”, plus other small, self-contained bugs from the open issues list
  • Linting rules — tightening up our oxlint/ruff configuration and fixing the violations that surface once a rule graduates from warning to error
  • Closing stale issues — triaging old issues to confirm whether they’re still reproducible, need more info, or can be closed
  • Reviewing open pull requests — Superset has a large PR backlog; giving PRs a careful read, testing them locally, and leaving useful feedback is just as valuable as writing new code
  • DRY / tidy-up fixes — finding duplicated logic, dead code, or inconsistent patterns across the codebase and cleaning them up
  • Building new extensions — Superset has a growing extensions framework for building new capabilities without forking core; the quick start guide is a good jumping-off point

We are moving fast, so by the time of the hackathon some of the issues we might point at today may be already solved, so we will have a curated list of issues for the hackathon participants close to the date.
