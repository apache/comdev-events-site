### Coordinator

* **Sergey Nuyanzin** — snuyanzin@gmail.com

### What We're Working On

We're focusing on:

* **Move to GitHub Actions** — help migrate CI infrastructure to GitHub Actions
* **Build improvements** — streamline the build process for new contributors
* **First PR tasks** — well-scoped issues designed to help you land your first Flink contribution

### Getting Started Before the Event

To make the most of hackathon time, we recommend:

1. Clone the repo and get the build working: [setup instructions](https://nightlies.apache.org/flink/flink-docs-stable/docs/flinkdev/building/)
2. Browse the issue list and pick one that interests you
3. Introduce yourself on the dev@ list
