### What We're Working On

<!-- Describe the kinds of tasks participants can expect. Be as specific
     as you like — or link to a curated issue list. Indicate difficulty
     levels where possible so participants can self-select. -->

We will introduce you to NuttX RTOS and show you how to build and run it
from scratch on an embedded board. There will be twenty
[SONY Spresense](https://developer.spresense.sony-semicon.com/) IoT boards
available for demos and demonstrations.

You can also bring your favourite board and we can try to run NuttX on it as well.
See the [list of supported platforms](https://nuttx.apache.org/docs/latest/platforms/index.html).
